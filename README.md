# 🎥 About the App

Asroo Store is a dual-panel e-commerce app — a **User App** for browsing and purchasing products, and an **Admin Panel** for managing products, categories, users, and notifications. Built with Flutter using modern architecture and real-world features.

**Key Features:**
- 🔐 **Authentication** — Login, Sign Up with profile image
- 🌓 **Dark & Light Theme** support
- 🌐 **Localization** — English & Arabic
- 📄 **Pagination** for smooth infinite scrolling
- 🔔 **Notifications** — FCM & Local notifications
- ❤️ **Favorites** management
- 🔍 **Advanced Search** — by name & price range
- 🛒 **Cart** & **Product Details**
- 📊 **Admin Dashboard** — manage products, categories, users & notifications
- 📡 **GraphQL & RESTful APIs**

## 🛠️ Tech Stack

| Category | Technologies |
| :--- | :--- |
| **Core & Architecture** | Flutter, Dart, Clean Architecture, BLoC/Cubit |
| **State Management** | flutter_bloc |
| **Networking** | GraphQL & RESTful APIs, Dio |
| **Dependency Injection** | GetIt |
| **Local Storage** | Hive, Shared Preferences |
| **Notifications** | Firebase FCM & Local Notifications |
| **Auth & Backend** | Firebase |
| **UI** | flutter_screenutil, cached_network_image |
| **Other** | Pagination, Localization (EN/AR), Dark & Light Theme |

## 🚀 How to Run

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/khaledmohd202/asroo-store.git
```

### 2️⃣ Install Dependencies
```bash
flutter pub get
```

### 3️⃣ Run the App
```bash
flutter run
```
